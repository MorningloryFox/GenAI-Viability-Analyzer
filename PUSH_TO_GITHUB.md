## 📤 Para fazer PUSH para GitHub

### OPÇÃO 1: Criar novo repositório (Recomendado)

```bash
# 1. Vá para: https://github.com/new
# 2. Crie um repositório chamado: GenAI-Viability-Analyzer
# 3. Deixe em branco (NÃO inicialize com README)
# 4. Copie a URL HTTPS (algo como: https://github.com/yourusername/GenAI-Viability-Analyzer.git)

# 5. Execute no terminal:
git remote add origin https://github.com/yourusername/GenAI-Viability-Analyzer.git
git branch -M main
git push -u origin main
```

### OPÇÃO 2: Usar SSH (se tem SSH configurado)

```bash
git remote add origin git@github.com:yourusername/GenAI-Viability-Analyzer.git
git branch -M main
git push -u origin main
```

## 🔑 Se Precisar de Autenticação

No Windows/PowerShell, use:

```powershell
# Será solicitado seu GitHub username e personal access token
git push -u origin main
```

**Gerar Personal Access Token:**
1. GitHub → Settings → Developer settings → Personal access tokens
2. Generate new token (classic)
3. Selecione: repo, workflow
4. Copie o token gerado
5. Use como senha no push
